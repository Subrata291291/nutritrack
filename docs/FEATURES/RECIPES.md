# Recipes Feature Specification

## Purpose

The Recipes module provides a centralized collection of healthy recipes that users can browse, search, save, cook, and add directly to their meal plans.

Recipes are composed of Food Library items and automatically calculate nutritional values based on their ingredients.

Recipes may be created manually by administrators or generated by AI in the future.

---

# Goals

The Recipes module should allow users to

- Browse recipes
- Search recipes
- Filter recipes
- View recipe details
- Save favorite recipes
- Add recipes to meal plans
- Log recipes as meals
- View nutritional information
- Discover recommended recipes
- Receive AI recipe suggestions (Future)

# Acceptance Criteria

The feature is complete when

- Users can browse recipes.
- Search and filters work correctly.
- Recipe details display correctly.
- Ingredients reference Food Library items.
- Nutrition values are calculated accurately.
- Recipes can be added to meal plans.
- Recipes can be logged as meals.
- Favorites work correctly.
- APIs follow API_CONTRACT.md.
- Loading and error states are implemented.
- UI matches the approved design.
- AI-generated recipes are saved as drafts and require admin approval before publication.
